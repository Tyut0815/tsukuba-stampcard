# 大阪つくば開成高校 コース発表会スタンプラリー

スマホで使う電子スタンプラリーです。GitHub Pages で配信します。

- 公開URL: https://tyut0815.github.io/tsukuba-stampcard/
- 設定（スポット名・場所・合言葉・感想文フォームURL・係員PIN）は `index.html` の先頭にある `CONFIG` で変更できます。
- 各スポットのQRコードは `公開URL#token` を指しています。`token` を変えたらポスターも作り直してください。
- スタンプの記録は参加者のブラウザ（localStorage）に保存されます。

## GitHub Pages の有効化
Settings → Pages → Build and deployment で「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save。
